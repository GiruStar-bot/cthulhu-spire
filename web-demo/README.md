# クトゥルスパイア — Webデモ（日本語）

Grok Build 上で動かしている **プレイ可能なデモ** のソーススナップショットです。

## 含まれるもの

- ターン制デッキビルダー戦闘（エネルギー / ブロック / 正気）
- クラス2種：探究者・信者
- 分岐マップ、イベント、休息、報酬、エリート、ボス
- カード・遺物・敵データ
- 生成アート（`public/art/`）

## ディレクトリ

```
web-demo/
├── public/art/              # タイトル・ポートレート・カード絵
├── src/game/                # ルール・カード・戦闘・ストア
├── src/components/game/     # 画面UI
├── src/routes/              # TanStack Start ルート
└── src/styles.css           # テーマトークン
```

このフォルダ単体ではビルドできません。実行環境は Grok のプレビュー（React 19 + TanStack Start + Tailwind v4 + zustand）に依存しています。ゲームロジックの本体は `src/game/` です。

## 操作

1. 登攀を始める → クラス選択
2. マップで道を選ぶ
3. カードをタップしてプレイ（対象が必要なときは敵をタップ）
4. ターン終了
