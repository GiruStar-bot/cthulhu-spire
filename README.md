## 確定しているゲーム像

死ぬまで続く無限沈降。死亡でその人生はリセットされる。プレイヤーは単独の潜航者。ルルイエは下へ行くほど層が増える。

| | 本線 |
|--|------|
| 終了 | 体力0のみ。クリア／エンディングなし（デモは第100層で一旦閉じる） |
| 進行 | 第1層、第2層…を直線で沈む（マップ全容は出さない） |
| 通常階層 | 戦闘が主。カード・回復・正気イベント等がランダム混在 |
| 10の倍数 | **中ボス**（必ず接敵） |
| 50の倍数 | **大ボス**（必ず接敵） |
| 引き継ぎ | 死亡するまで体力・正気・デッキ・遺物を保持 |
| テーマ | 知識は両刃。正気は通貨。恐怖を優先 |

詳細・未確定項目は [docs/GAME_VISION.md](docs/GAME_VISION.md)。
