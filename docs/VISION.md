# Vision

本線仕様の全文は [GAME_VISION.md](./GAME_VISION.md) を正とする。

## 一行で

黒き尖塔を、正気を削りながら登り続ける宇宙的恐怖のデッキビルダー。死ぬまで終わらない。

## プレイヤー体験の核

- 最初は探究者／信者として尖塔に足を踏み入れる
- 知識を得るたびに強くなるが、同時に正気を失っていく
- ランにエンディングはない。死亡がその人生のリセット
- 記録に残るのは「どこまで登ったか」「何を見てしまったか」

「強くなったのに、勝っても怖くなった。そして、終わりがない。」
