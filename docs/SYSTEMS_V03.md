## 1. 遺物（永久収集 + 持込6枠 + ハクスラ）

### 概念

- 遺物は**一度得たらアカウントに永久蓄積**される（ラン外コレクション）。
- 登攀に**持ち込めるのは最大6つ**（ロードアウト）。
- 同じテンプレートでも、ドロップ時に**数値がロール**される（ハクスラ的バラつき）。
- **高い階層のボスほど、基準ステータスが高い**。ロールで上下する。

### フロー

1. ボス／エリート撃破 → 遺物インスタンス生成（tier + roll）
2. コレクションに追加（永久）
3. 次ラン開始前、所持品から最大6つを装備
4. ラン中は装備中の6つのみが効果を発揮

### ロール式（たたき台）

```
base = tierBase[tier]
rolled = clamp(round(base * (0.85 + rand * 0.30)), min, max)
```

tier は到達階層帯（例: 1–19 → T1、20–49 → T2、50+ → T3…）。

### 持込上限

`MAX_LOADOUT = 6`（本版で固定。後から変更可）

## 3. プレイヤー像（RPG的成長）

ジョブ固定の二択ではなく、**名前と思想（ステータス）**で自分の器を作る。

### 永続プロフィール

| フィールド | 内容 |
|------------|------|
| playerName | プレイヤーが設定する名前 |
| body | 肉体・筋力寄りの成長 |
| mind | 知識・正気寄りの成長 |
| will | 意志・儀式耐性 |
| collection | 所持遺物インスタンス一覧 |
| loadoutIds | 次ランに持ち込む最大6件の uid |
| bestFloor / runs | メタ記録 |

### ステータスの意味（初期）

| ステータス | 効果 |
|------------|------|
| body | 最大体力 +2 / 点 |
| mind | 最大正気 +2 / 点 |
| will | 開始時ブロック傾向・耐性（後続で拡張） |

初期配点: 合計 **12点** を自由配分（各ステ最低1）。

### 条件解放（好奇心・自由）

ステータスが閾値に達すると、カード／防具的パッシブ／儀式が解禁される。

例:

| 条件 | 解放 |
|------|------|
| body ≥ 6 | 打撃強化系の初期候補 |
| mind ≥ 6 | 禁書・研究系カード |
| will ≥ 6 | 儀式系の一部 |
| body+mind+will ≥ 20 | 特別な遺物スロット演出（将来） |

イベントやラン間の選択でステータスを伸ばせる（本版は準備画面の配点＋記録の骨格を優先）。
