# ゲーム像（正）

死ぬまで続く無限沈降。死亡でその人生はリセット。プレイヤーは単独。ルルイエは下へ行くほど第N層が増える。

## 核心

| 項目 | 内容 |
|------|------|
| 終了 | 体力 0 のみ。クリア／エンディングなし（デモは第100層） |
| 進行 | 第1層, 第2層… 直線（マップ全容は出さない） |
| 10倍 | 中ボス |
| 50倍 | 大ボス |
| 引き継ぎ | 死亡まで HP・正気・デッキ・遺物 |
| テーマ | 知識は両刃。正気は通貨。恐怖優先 |
| UI | 腐った日誌／カード外見。戦闘の数字は腐らせない |

## 潜航前点検
湿った日誌。名前・器の配分・遺物ロードアウトを決めて沈降開始。ボタンを押せばただちに第1層へ沈む。
