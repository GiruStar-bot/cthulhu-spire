# ゲーム像（正）

死ぬまで続く無限登攀。死亡でその人生はリセット。

## 核心

| 項目 | 内容 |
|------|------|
| 終了 | 体力 0 のみ。クリア／エンディングなし |
| 進行 | 階層 1,2,3… 直線（マップ分岐なし） |
| 10倍 | 中ボス |
| 50倍 | 大ボス |
| 引き継ぎ | 死亡まで HP・正気・デッキ・遺物 |
| テーマ | 知識は両刃。正気は通貨。恐怖優先 |
