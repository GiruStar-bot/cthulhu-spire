## 1. テーマ（確定）

**黒き尖塔を、正気を削りながら登り続ける宇宙的恐怖のデッキビルダー。**

死ぬまで終わらない。勝って「クリア」する物語ではなく、**どこまで耐え、どこまで知ったか**がランの記録になる。

### デザインの柱

1. **宇宙的無力感と主体性の幻想** — プレイヤーは強く感じるが、塔と宇宙は無関心か敵意を持つ。
2. **知識の両刃性** — 力・カード・儀式は得られるが、正気を削る。
3. **正気（Sanity）が中核リソース** — 体力と並ぶ第二の生命線。
4. **儀式的なデッキ構築** — カードは呼び、封じ、取引する行為。
5. **恐怖の優先** — パワーファンタジーより、徐々に侵食される感覚。

### プレイヤー像（暫定）

| 系統 | イメージ | 傾向 |
|------|----------|------|
| 探究者 | 壊れた学者・記録する生存者 | 肉体寄り、正気は脆い |
| 信者 | 自ら開く器 | 儀式・供物寄り、正気を払う |

ラン内の勝利条件は存在しない。達成感は到達階層・撃破ボス・残した記録に置く。

## 2. システム（確定）

### ラン構造

| 項目 | 確定内容 |
|------|----------|
| 終了条件 | **死亡のみ**（体力0） |
| クリア／エンディング | **なし**（死ぬまで続く） |
| 死亡時 | そのランの人生リセット。メタ記録（最高到達階層など）は残してよい |
| 進行単位 | **階層 1, 2, 3…** の直線登攀 |
| マップ選択 | **廃止** |

### 開始

1. 「登攀を始める」
2. （必要なら）クラス選択
3. **第1階層**から開始
4. 遭遇を解決し、次階層へ

### 各階層で起きうること

基本は**敵との戦闘**。どの階層でも次がランダムに発生しうる。

| 種別 | 例 |
|------|----|
| 戦闘 | 通常敵との接敵 |
| カード | 入手・選択・強化 |
| 回復 | 体力回復 |
| 正気イベント | チェック・消費・回復・リスク選択 |
| その他 | 予兆・取引・選択テキスト |

出現比率は未確定。

### 固定階層（優先度高）

| 条件 | 内容 |
|------|------|
| **50の倍数**（50, 100, 150…） | **大ボス**と必ず接敵 |
| **それ以外の10の倍数**（10, 20, 30, 40, 60…） | **中ボス**と必ず接敵 |
| 上記以外 | 通常戦闘または各種イベント等をランダム |

10階層ごとに必ずボス。ボス階層をイベントだけで済ませることはない。

### リソース

ラン中、死亡するまで **体力・正気・デッキ・遺物は引き継ぐ**。

| リソース | 役割 |
|----------|------|
| 体力 | 0でラン終了 |
| 正気 | 知識・儀式のコスト |
| エネルギー | 戦闘中の行動リソース |
| ブロック | 被ダメージ軽減 |
| デッキ | 成長・汚染されうるカード集合 |
| 遺物 | 永続パッシブ |

## 3. 現行Webデモとの差分

公開中のデモは旧骨格（三面・マップ分岐）のまま。本線は以下へ作り替える。

| 項目 | 現行デモ | 本線 |
|------|----------|------|
| ラン終了 | 三面ボス撃破で勝利、または死亡 | **死亡のみ** |
| 構造 | 一面／二面／三面＋マップ分岐 | **無限階層の直線登攀** |
| 進行UI | ノード選択マップ | 階層表示＋遭遇解決 |
| ボス | 面末ボス | 10の倍数＝中ボス、50の倍数＝大ボス |
| イベント | マップ上の予兆ノード | 通常階層にもランダム混在 |

カード・正気・戦闘ルールの一部は流用可。進行骨格は作り直し前提。

## 4. 未確定（これから詰める）

- 通常階層の遭遇比率
- 階層上昇に伴う戦闘密度
- 中ボス／大ボスのプールとスケール
- 正気0の具体ルール
- 回復量、遺物入手、カード強化の置き場
- メタ記録（最高階層、解放など）
- 階層の呼び名、ボス固有名
- 本実装エンジン（現行は Web デモ）

推奨する決定順: **遭遇比率 → ボス定義 → 正気0 → 報酬整理 → メタ記録**

## 5. 要約

- テーマは Slay the Spire × クトゥルフ神話。
- 正気は体力と並ぶ中核。知識は両刃。
- ランは死ぬまで終わらない。死亡で人生リセット。
- 進行は階層の直線登攀。分岐マップと三面制は採用しない。
- 10の倍数は中ボス、50の倍数は大ボス。それ以外は戦闘中心にイベント混在。
