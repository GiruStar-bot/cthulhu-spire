# Technical Notes

## 推奨エンジン
**Godot 4.x**

理由:
- 2Dデッキビルダーとの相性が非常に良い
- Resourceシステムがカード・レリック・イベント管理に最適
- 無料・軽量・オープンソース
- カスタム描画やシェーダーで非ユークリッド表現がしやすい

## 代替
Unity（C#） — 既にUnity経験が強い場合

## コアアーキテクチャ方針
1. データ駆動（CardDefinition / RelicDefinition などをResourceで持つ）
2. コンバットシミュレーション（純粋ロジック）とUIの分離
3. Sanityを第一級リソースとして扱い、他システムからクエリ可能にする
4. 決定論的な戦闘（シード再現性を重視）

詳細は `cthulhu-spire-engine` スキルを参照。
