# Technical Notes

## 現行デモ

- React 19 + Vite + Tailwind v4 + zustand
- 静的サイト。GitHub Pages（`gh-pages` ブランチ）
- アートパスは `import.meta.env.BASE_URL` 経由（`src/lib/asset.ts`）

## 本線で必要な進行ロジック

遭遇決定は **重み付き乱数 + 固定階層オーバーライド**。

```
if floor % 50 === 0      → 大ボス
else if floor % 10 === 0 → 中ボス
else                     → 通常テーブル（戦闘／イベント／回復／カード）
```

階層を跨いで体力・正気・デッキ・遺物を保持。体力0でラン終了。

## 本実装の候補

Godot 4.x を推奨（データ駆動のカード／遺物、2Dとの相性）。  
現行 Web デモは方針検証用。

## アーキテクチャ方針

1. データ駆動（カード・遺物・敵・イベント定義）
2. 戦闘ロジックと UI の分離
3. 正気を第一級リソースとして他システムから参照可能にする
4. 可能なら決定論的戦闘（シード再現）
