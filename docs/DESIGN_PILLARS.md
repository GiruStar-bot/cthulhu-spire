# Design Pillars - Cthulhu Spire

## 1. Cosmic Insignificance with Agency Illusion
プレイヤーはデッキ構築と巧妙なプレイで「強い」と感じるが、最終的に宇宙は無関心か、あるいはプレイヤーの存在を許容していない。  
勝利は一時的なものであるべき。

## 2. Knowledge as Double-Edged Power
Insight / 禁断の知識 / 高ティアカードを得ることは機械的な強さを増すが、Sanityを削り、危険な選択肢やマップ変化を引き起こす。

## 3. Ritualistic Deckbuilding
カードは「技」ではなく「儀式・呪文・印」として感じられること。  
プレイすること自体が「何かを呼び寄せている」感覚を持たせる。

## 4. Non-Euclidean Atmosphere
マップ、イベントテキスト、敵の意図、ビジュアルに「角度が合わない」「空間がおかしい」感覚を織り込む。  
ただしゲームプレイの明快さを壊さない範囲で。

## 5. Dread over Power Fantasy
ユーモアは抑制的に。  
恐怖は暗示とコストと「もう手遅れだった」という気づきから生まれる。
